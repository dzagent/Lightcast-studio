# LightCast Studio

برنامج إنتاج تلفزيوني خفيف ومفتوح المصدر (MIT): مزج كاميرات وشاشة وفيديو وصور وعناوين،
مشاهد وطبقات علوية، Chroma Key، **تراجع/إعادة (50 خطوة)**، تسجيل MP4، وبث RTMP متعدد المنصات.

## الحصول على ملفات التثبيت (Windows + Mac)

ملفات التثبيت تُبنى على كل نظام بنفسه، لذلك أسهل طريقة هي GitHub Actions (مجاناً):

1. أنشئ مستودعاً جديداً على GitHub وارفع محتوى هذا المجلد كما هو.
2. افتح تبويب **Actions** ← **Build installers** ← **Run workflow**.
3. بعد 5–10 دقائق نزّل من أسفل صفحة التشغيل (Artifacts):
   - `LightCast-windows` ← ملف `.exe` (مثبّت Windows)
   - `LightCast-mac-apple-silicon` ← ملف `.dmg` (Mac بمعالج M1/M2/M3/M4)
   - `LightCast-mac-intel` ← ملف `.dmg` (Mac بمعالج Intel)

أو ابنِ محلياً على نفس النظام: `npm install` ثم `npm run dist` (الناتج في مجلد `release/`).

### تنبيهات التثبيت
- الملفات غير موقّعة رقمياً: في Windows اضغط **More info ← Run anyway**.
  في Mac: كليك يمين على التطبيق ← **Open** (أول مرة فقط).
- على Mac وافق على صلاحيات الكاميرا والميكروفون وتسجيل الشاشة.

## التطوير
```
npm install
npm run dev     # وضع التطوير
npm start       # بناء وتشغيل
```

## الاختصارات
`Space` قطع · `Enter` تلاشي · `Ctrl/⌘+Z` تراجع · `Ctrl/⌘+Shift+Z` إعادة · `F9` تسجيل

## الجديد في 0.3
- **واجهة جديدة** بتخطيط يجمع vMix (معاينة وبث وعمود انتقالات وشريط مشاهد) وOBS (لوحات المصادر والخصائص والصوت والتحكم) مع شريط حالة وقوائم.
- **المشاريع**: جديد / فتح / حفظ / حفظ باسم (ملفات `.lcs`)، حفظ تلقائي كل 30 ثانية واستعادته من قائمة ملف.
- **تعديل مباشر**: سحب الطبقة وتغيير حجمها من زاوية المعاينة، وإعادة تسمية المشاهد بالنقر المزدوج.
- **الإعدادات**: جودة البث والتسجيل، عدد الإطارات، لون التمييز (4 ألوان)، اللغة.
- لقطة شاشة PNG، واختيار المشهد بالأرقام 1–9.

## الجديد في 0.2
- **مازج صوت**: مستوى (فيدر) وكتم وعدّاد لكل مصدر، ومستوى رئيسي، وسماعة مراقبة (🎧).
- **انتقالات**: تلاشي، مسح، انزلاق، عبر الأسود، بمدة قابلة للاختيار، مع **شريط انتقال يدوي (T-bar)**.
- **عرض متعدد (Multiview)**: صورة حية لكل مشهد؛ نقرة = معاينة، نقرتان = بث مباشر.

## حدود النسخة الحالية
- نموذج أولي: الواجهة والمزج بتقنيات الويب (Electron + React)، وليس نواة C++ الأصلية.
- البث عبر FFmpeg المرفق (H.264/AAC بسرعة 3 Mbps)، والتسجيل يُحوَّل إلى MP4 عند الحفظ.
- لا يوجد بعد: NDI، استوديو 3D، حفظ/فتح المشاريع، Instant Replay.
